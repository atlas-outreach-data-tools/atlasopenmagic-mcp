# Security Policy

## Scope

`atlasopenmagic-mcp` is a read-only MCP server over public ATLAS Open Data.
It has no authentication and handles no personal or restricted data.
See "Security and data" in the [README](README.md).

## Reporting a vulnerability

Use GitHub private vulnerability reporting:
<https://github.com/atlas-outreach-data-tools/atlasopenmagic-mcp/security/advisories/new>

Do not open a public issue for a vulnerability. We aim to reply within 7 days.

## Supported versions

Only the latest release receives fixes.

Questions and bugs: <https://github.com/atlas-outreach-data-tools/atlasopenmagic-mcp/issues>
